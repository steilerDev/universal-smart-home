# PCB Distribution Board A

First of the two-board distribution set for the room sensor unit.

## Design Files

Place Fusion 360 / EDA source files here alongside exported assets:
- `schematic.pdf` — exported schematic for reference without CAD software
- `bom.csv` — bill of materials
- `gerber/` — Gerber files for PCB fabrication
